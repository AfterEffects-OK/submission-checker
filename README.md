# 課題提出状況 検索システム (index.html)

学校・講義における学生の課題提出状況をリアルタイムで検索・確認できる、モダンで軽量なWebアプリケーション（フロントエンド単体 / Google Apps Script (GAS) バックエンド連携）です。

---

## 🚀 主な機能

1. **リアルタイム検索**
   - 学生の氏名（フルネーム、スペース除去対応）を入力し、即座に該当者の各課題の提出状況をリストアップします。
   - `Enter`キーでのクイック検索にも対応しています。
2. **提出状況のステータス自動判定**
   - **提出済み**: 提出フラグが有効かつ有効な動画拡張子（`.mp4`, `.mov`, `.avi`, `.m4v`, `.wmv`, `.mkv`, `.webm`, `.flv`）が含まれている場合。
   - **評価不能ファイル**: 提出フラグは立っているものの、許可されていない拡張子の場合。
   - **未提出**: 未提出の状態（期限超過の場合は期限日時の文字色が赤色に変化）。
3. **レスポンシブデザイン & ダークモード対応**
   - PC向けには詳細なテーブルレイアウト、スマートフォン向けには直感的なカード型リスト（2段レイアウト）に自動切り替えします。
   - 画面右上のトグルボタンで「ライトモード」と「ダークモード」を切り替え可能です（設定は `localStorage` に保存）。
4. **Google Drive & スプレッドシート連携**
   - 提出物ごとの Google ドライブフォルダへのダイレクトリンク (`フォルダを開く ↗`) を提供。

---

## 🛠️ 技術スタック

- **HTML5 / CSS3**: カスタムプロパティ（CSS Variables）による柔軟なテーマ切り替え、レスポンシブデザイン
- **JavaScript (ES6+)**: `fetch` APIによるGASバックエンドとの非同期通信、状態管理、動的DOMレンダリング
- **バックエンド連携**: Google Apps Script (GAS) Webアプリエンドポイント

---

## ⚙️ セットアップ・使い方

1. `index.html` を任意のWebサーバーまたは GitHub Pages にホストします。
2. ソースコード内の `GAS_URL` 変数を、ご自身のGoogle Apps ScriptデプロイメントURLに書き換えてください。
3. ブラウザでアクセスし、検索窓に学生氏名を入力して「検索する」をクリックします。


# 講義管理・ダッシュボードシステム (dashboard.html)

受講学生の提出状況や進捗、各種講義データの一括管理・モニタリングを行うための管理画面・ダッシュボードアプリケーションです。

---

## 🚀 主な機能

1. **統合ダッシュボードビュー**
   - 複数講義やクラスの課題提出状況、達成率、未提出者のリストを一目で把握できます。
2. **フィルタリングとデータ集計**
   - 前期・後期などのターム別、必修・選択別の絞り込みや、ステータスごとの集計をスムーズに行えます。
3. **管理・運用効率化ツール**
   - データの確認、各学生の提出フォルダへのクイックアクセス、評価ステータスの確認を効率化します。
4. **ダークモード対応**
   - 長時間の作業でも目が疲れにくいダークモードを標準搭載しています。

---

## 🛠️ 技術スタック

- **HTML5 / CSS3**: モダンなダッシュボードUIデザイン
- **JavaScript (ES6+)**: 動的なデータバインディングとフィルター処理

---

## ⚙️ 使い方

1. `dashboard.html` を `index.html` と同一の環境（または対応するGASバックエンド連携先）に配置します。
2. ブラウザから開き、管理・モニタリング業務にご活用ください。

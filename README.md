# 課題提出状況 検索システム (index.html)

学校・講義における学生の課題提出状況をリアルタイムで検索・確認できる、モダンで軽量なWebアプリケーション（フロントエンド単体 / Google Apps Script (GAS) バックエンド連携）です。

---

## 🚀 主な機能

1. **リアルタイム検索**
   - 学生の氏名（フルネーム、スペース除去対応）を入力し、即座に該当者の各課題の提出状況をリストアップします。
   - `Enter`キーでのクイック検索にも対応しており、スムーズな情報の突き合わせが可能です。
2. **提出状況のステータス自動判定**
   - **提出済み**: 提出フラグが有効かつ有効な動画拡張子（`.mp4`, `.mov`, `.avi`, `.m4v`, `.wmv`, `.mkv`, `.webm`, `.flv`）が含まれている場合。
   - **評価不能ファイル**: 提出フラグは立っているものの、許可されていない拡張子の場合。
   - **未提出**: 未提出の状態（期限超過の場合は期限日時の文字色が赤色に変化し、遅延を一目で警告）。
3. **レスポンシブデザイン & ダークモード対応**
   - PC向けには詳細なテーブルレイアウト、スマートフォン向けには直感的なカード型リスト（2段レイアウト）に自動切り替えします。
   - 画面右上のトグルボタンで「ライトモード」と「ダークモード」を切り替え可能です（設定は `localStorage` に自動保存）。
4. **ローカル保存の無効化オプション（`nosave`）**
   - URL に `?nosave=1`、`?nosave=true`、`?nosave`、または `#nosave` を付与することで、学生氏名の `localStorage` 保存および自動復元を無効化できます（共用端末利用時向け）。
   - 無効化指定で開いた際は、既存の保存済み氏名（`saved_search_keyword`）も削除されます（ダークモード設定は維持）。
   - **表示内容と解説**: `nosave` 指定時は前回検索した氏名が検索入力欄に自動復元されず、空欄の初期状態から表示されます。教室の共用PCや他人の画面と共有する場面で、直前の利用者の氏名が画面やブラウザストレージに残るのを防ぐための仕組みです。
5. **Google Drive & スプレッドシート連携**
   - 提出物ごとの Google ドライブフォルダへのダイレクトリンク (`フォルダを開く ↗`) を提供し、ワンクリックで成果物の実データにアクセスできます。
   - 「学生」シートの **P列（`is除籍フラグ`）** が `TRUE` の学生はバックエンド側で除外され、除籍生のデータが検索結果に表示されません。
   - **表示内容と解説**: `is除籍フラグ` が `TRUE` の学生レコードは集計対象から外されるため、在籍中の学生データのみが検索・表示されます。

---

## 🛠️ 技術スタック

- **HTML5 / CSS3**: カスタムプロパティ（CSS Variables）による柔軟なテーマ切り替え、レスポンシブデザイン
- **JavaScript (ES6+)**: `fetch` APIによるGASバックエンドとの非同期通信、状態管理、動的DOMレンダリング
- **バックエンド連携**: Google Apps Script (GAS) Webアプリエンドポイント

---

## ⚙️ セットアップ・使い方

1. `index.html` を任意のWebサーバーまたは GitHub Pages にホストします。
2. ソースコード内の `GAS_URL` 変数を、ご自身のGoogle Apps ScriptデプロイメントURLに書き換えてください。
3. ブラウザでアクセスし、検索窓に学生氏名を入力して「検索する」をクリックします（保存を残したくない場合は `?nosave=1` 付きURLを利用）。

# 講義管理・ダッシュボードシステム (dashboard.html)

受講学生の提出状況や進捗、各種講義データの一括管理・モニタリングを行うための総合管理画面・ダッシュボードアプリケーションです。

---

## 🚀 主な機能

1. **統合ダッシュボードビュー**
   - 複数講義やクラスにおける課題の提出状況、全体および個別の達成率、未提出者のリストを一目で把握できます。
   - 「学生」シートの **P列（`is除籍フラグ`）** が `TRUE` の学生は対象者数・提出率の集計から除外されます。
   - **表示内容と解説**: 課題ごとの提出状況（`提出数 / 対象者数`）や提出率、展開時の学生別カード一覧から除籍学生が除外されます。除籍生を分母に含めないことで、現在の在籍者基準での正確な提出率を把握できます。
2. **学科フィルター & 高度なフィルタリング・データ集計**
   - URL クエリパラメータ（`gakka` / `idGakkaId` / `id学科`）を指定することで、対象学科の課題・提出状況に絞り込み表示できます（例: `?gakka=f6765d6d`）。
   - 画面上部のフィルターバッジは学科名のみを表示する形式（例: `学科フィルター: 映像音響学科`）に整理されています。
   - **表示内容と解説**: 学科絞り込みが有効なときはヘッダー下に `学科フィルター: 映像音響学科` のようなバッジが表示され、対象学科の科目・課題に絞られた一覧が表示されます。内部ID（`f6765d6d` など）の括弧表記を省いて学科名のみを表示することで、画面上の視認性とスッキリ感を高めています。
   - 講義名・課題タイトルでの絞り込みや、提出状況順・提出率順などのソート、自動更新・アニメーションディレイ設定に対応しています。
3. **管理・運用効率化ツール**
   - 学生別カードの展開表示、個別データの再取得（`再取得` ボタン）、各課題の提出フォルダへのクイックアクセス、評価ステータスの確認作業を効率化します。
4. **ダッシュボードの設定項目と解説**
   - **ディレイ（`0.01秒`〜`0.7秒`、既定: `ゆっくり (0.3秒)`）**: 課題を展開したときに学生カードが順番に落ちて表示されるアニメーションの時間間隔を設定します。人数が多いクラスや画面共有・録画時は短め、提出の流れを追いやすい確認時は長めなど用途に合わせて調整できます。
   - **自動更新（`オフ` / `30秒ごと` / `1分ごと` / `5分ごと` / `15分ごと` / `30分ごと` / `1時間ごと` / `12時間ごと`）**: 定期的にバックエンドから最新データを取得し、変更があった課題や新規提出となった学生カードを自動で更新・ハイライトします（設定は `localStorage` に保存）。
   - **タイトルを非表示 / タイトルを表示**: 画面上部の見出し・サブタイトル・学科フィルターバッジ領域をスムーズに開閉します。投影や省スペース表示で一覧表の縦幅を広く使いたいときに便利です。
   - **検索・フィルターを非表示 / 検索・フィルターを表示**: 「講義名」「課題タイトル」のプルダウン絞り込みエリアを開閉します。一覧の閲覧や確認に集中したいときに折りたたんで使えます。
   - **ダークモード / ライトモード**: 画面全体の配色を切り替えられます（`localStorage` に保存、未設定時はOS/ブラウザのテーマ設定に追従）。
   - **並べ替え（学生別カード内: `氏名順` / `提出状況順 (昇順)` / `提出状況順 (降順)`）**: 課題詳細を展開した際の学生カードを並び替えます。`氏名順` はふりがな（未設定時は氏名）順、`提出状況順 (昇順)` は未提出・評価不能を優先して表示するため、未提出者の拾い出しに役立ちます。
   - ※ 画面幅が狭いときは、これらの操作項目が `メニュー` ボタン内のドロップダウンに集約されます。
5. **ダークモード対応**
   - 長時間の事務作業やデータ監視でも目が疲れにくいダークモードを標準搭載しています。

---

## 🛠️ 技術スタック

- **HTML5 / CSS3**: モダンで洗練されたダッシュボードUIデザイン
- **JavaScript (ES6+)**: 動的なデータバインディング、フィルタリング、リアルタイム集計処理

---

## ⚙️ 使い方

1. `dashboard.html` を `index.html` と同一の環境（または対応するGASバックエンド連携先）に配置します。
2. ブラウザから直接開き（必要に応じて `?gakka=f6765d6d` などの学科指定を付与し）、教職員の管理・モニタリング業務や成績評価のサポートにご活用ください。
